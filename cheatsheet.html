Settings

Select a setting with its panel button. PLAY saves and exits; SEQ OCT switches coarse / fine adjustment. Full settings instructions.

Pitch modeSEQ 2 · OSC2

EG cycles Normal → Paraphonic → Harmony → Morph. NEXT / RESET move one mode forward / back.

Rhythm typeSEQ 2 · SUB1

EG toggles Stock / Gate Patterns. NEXT selects Gate Patterns; RESET selects Stock.

NoiseSEQ 2 · SUB2

EG toggles noise on VCO2 SUB2. NEXT turns it on; RESET turns it off. Use the SUB2 mixer level to blend it.

Harmony spreadSEQ 1 · OSC1

Detunes the voices within ±30 cents. NEXT / RESET adjust the amount; EG switches between zero and the recalled amount.

GlideSEQ 1 · SUB1

EG turns MIDI legato glide on / off. NEXT / RESET select roughly 10, 22, 50, 100, 200, 500, 1000, or 2000 ms; SEQ OCT enables fine adjustment. All eight step LEDs (SEQ1 then SEQ2) show the nearest time preset; the default 22 ms lights two. EG shows on / off independently. Times are RC time constants. Applies to overlapping MIDI notes, not internal sequence steps.

Velocity depthSEQ 1 · SUB2

NEXT / RESET adjust MIDI velocity sensitivity. EG switches between zero and the recalled depth. Affects the shared VCA.

Tuning spanQUANTIZE

EG toggles ±1 / ±2 octaves around the remembered pitch. NEXT selects ±2; RESET selects ±1. Separate from the sequencer octave range.

Pitch modes

Normal

Stock oscillator tuning and subharmonic divisions. Choose Stock rhythms for the original divider routing, or Gate Patterns for separate pitch and envelope rhythms.

Paraphonic

FREQ knobs
Each source has its own pitch. Noon is the allocated MIDI note, or middle C when free; the knob offsets it by ±1 or ±2 octaves.
Sequencers
Assignments add pitch to the selected sources. QUANTIZE applies to all six.
MIDI
Each note allocates one source. Note Off snaps that source back to its neutral middle-C anchor, retaining knob and sequencer offsets. Unallocated sources stay neutral. All sources share one filter and VCA, so the return can be audible in the release tail.

Harmony

The four subs play root, third, fifth and seventh. The main VCOs add bass and melody.

VCO1
Chord root. Plays bass one octave below the root.
VCO1 SUB1
Scale. This source plays the chord root.
VCO1 SUB2
Key. This source plays the third.
VCO2
Independent melody within the scale.
VCO2 SUB1
Inversion. This source plays the fifth.
VCO2 SUB2
Voicing: close, drop 2, drop 3, open. This source plays the seventh.

Sequence assignments move the matching knob function. Assign only SEQ 1 OSC1 to begin with chord changes; add SEQ 2 OSC2 for melody. QUANTIZE retains ET/JI tuning.

Scale order

Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian, harmonic minor, Locrian natural 6, Ionian sharp 5, Dorian sharp 4, Phrygian natural 3, Lydian sharp 2, Super Locrian.

Morph

MIDI
Each note plays VCO1 and VCO2 together, retaining their tuning offsets. SUB2 modulation rates stay independent of MIDI notes; SUB1 timing follows its parent. Note Off retains the latest pitch.
SUB1 FREQ
Scans even, alternating, Brake, Accelerate, double burst, triple burst, irregular and single cluster shapes.
SUB2 FREQ
Modulates SUB1 reset timing. SUB2’s mixer can stay down. Timing changes affect pitch as well as timbre.
SUB1 assignment
Sequences shape. Step noon is neutral; start with SUB1 FREQ near noon.
SUB2 assignment
Sequences the modulation rate.
PLAY / STOP
PLAY adds bar restarts and pulls selected clicks toward sixteenths. STOP returns to free timing.
Main VCO PWM
The middle waveform-switch position uses SUB1 to modulate pulse width, even with SUB1’s mixer down. A PWM cable overrides it.

Brake and Accelerate sit around 29% and 43% of the SUB1 knob. VCO2 SUB2 noise bypasses its periodic timing modulation.

Rhythms

Gate Patterns: R1 / R2 route to SEQ1 (upper button) and SEQ2 (lower). R3 / R4 route to VCA (upper) and VCF (lower). Light both buttons for both destinations; turn both off to disconnect the lane.

Stock: all four rhythms divide the clock and route to SEQ1 / SEQ2. SEQ1 hits trigger both envelopes. CC113 selects OR or exclusive-one; Gate Patterns always uses OR.

PLAY pauses / resumes. RESET restarts. NEXT advances both pitch sequences without moving the rhythm or firing envelopes.

CLOCK IN: one edge per sixteenth in Gate Patterns, or per divider count in Stock. CLOCK OUT follows physical edges. Internal / MIDI clock uses 24 PPQN with sixteenth CLOCK OUT. TEMPO: 40–239 BPM.

Gate patterns — 32 patterns, 64 steps each

Rows are bars 1–4. Each square is a sixteenth; filled squares are hits. Many patterns vary in bars 3–4. Numbers follow the rhythm knob from counterclockwise to clockwise.

MIDI

CC changes are temporary. Panel settings save with PLAY or after 30 seconds idle. For persistent MIDI settings, use feature_config.py.
